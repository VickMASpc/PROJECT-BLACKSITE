# PLAYER DESIRE BIBLE

Status: **Authoritative preference document**

BLACKSITE is a private project for one player. The player’s tastes are not one input among many; they are the deciding design criterion.

The project does **not** need balanced fetish representation, broad-market erotic appeal, or a checklist of different adult mechanics.

If one concept is disproportionately appealing, it is allowed to receive disproportionate development.

If a scene is theoretically clever but not personally exciting, it loses.

If a recurring idea remains exciting after multiple uses, repetition is a feature, not a design failure.

# 2. Desire-first scene rule

Before designing a scene, ask:

> If the stealth game, lore, progression system, and technical cleverness disappeared, would the core situation still be hot/funny/fucked-up enough that the player would want to watch/play it?

If no, the scene is weak.

Worldbuilding and gameplay should **support** the erotic premise, not replace it.

---

# 3. Specificity over abstraction

Do not summarize desirable physical events into vague states such as:

- “compromised”
- “high strain”
- “reduced composure”
- “device interference”

Those can exist internally, but the scene itself should know **what is actually happening**.

Example:

Weak:
> Reina is heavily compromised and loses composure.

Strong:
> One of the remaining balls has reached the exit and will not pass. Reina has been pushing for long enough that her legs are shaking. She can feel another device pressing behind it. The Commander can see the first one, but she still refuses help.

The latter creates actual content.

# 4. Repetition is allowed to deepen

If balls/capsules appear in three major scenes, those scenes should not merely repeat the same animation.

They should deepen different aspects:

- first time: shock, pride, refusal to ask for help
- later: the Commander knows exactly how to manipulate the procedure
- later still: Reina recognizes the setup early and tries to negotiate rules before it starts
- eventually: Reina may be the one who notices that carrying them is tactically useful and hates herself for suggesting it

The recurring idea becomes part of the relationship.

# 5. Humiliation must be personally satisfying

- being watched

Professional/reporting elements are **optional amplifiers**, not the core requirement.

The scene must remain desirable even without a formal report.

The scene should erode her control in layers rather than start with total collapse.
